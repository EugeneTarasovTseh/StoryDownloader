# StoryDownloader — Windows Beta 0.1.0-beta.2

**[Скачать Windows-бету](https://github.com/EugeneTarasovTseh/StoryDownloader/releases/tag/v0.1.0-beta.2)**

Программа сохраняет доступные вашему аккаунту истории Telegram в выбранную папку. Это независимое приложение; оно не является официальным продуктом Telegram.

## Начало работы
1. Распакуйте весь архив в отдельную папку и запустите StoryDownloader.exe.
2. Во вкладке «Настройки» выберите язык и введите собственные API ID, API Hash и номер телефона. Кнопка «Как получить API…» объясняет получение данных на https://my.telegram.org.
3. Выберите папку и нажмите «Скачать». Пустое поле пользователя означает ваш аккаунт. Для другого пользователя укажите его имя.
4. При первом входе введите код Telegram и, если включена, пароль двухэтапной проверки.

Архив собственных историй доступен в пределах возможностей Telegram API. Архив чужих историй может быть недоступен. Программа не обходит ограничения доступа. Сохраняйте и используйте материалы только с необходимыми разрешениями.

Файлы группируются по годам. Имена: ГГ.ММ.ДД-##.jpg / .mp4. Используется дата публикации в часовом поясе компьютера; это не подтверждённая дата съёмки. Пауза позволяет продолжить текущую загрузку, остановка завершает её. Повторный запуск проверяет сохранённые файлы. Сворачивание убирает приложение в трей; выход доступен через меню значка.

## Настройки и безопасность
Настройки, история и сессия находятся в %LOCALAPPDATA%\StoryDownloader. Не удаляйте индексы, если хотите сохранить сопоставление историй и переименованных файлов. После переноса папки выберите новый путь в настройках. Восстановление использует прежние индексы на этом компьютере; сохраняйте имена файлов и структуру папок. Старые записи без SHA-256 сопоставляются по относительному пути, новые дополнительно проверяются по содержимому.

API Hash, номер телефона и настройки сохраняются локально в незашифрованном виде. Файл сессии содержит данные авторизации. Никому не передавайте эти файлы, не прикладывайте их к обращениям и не загружайте на GitHub. API ID является идентификатором приложения, а не паролем; пару API ID + API Hash публиковать не следует. Для отзыва текущей сессии используйте «Выйти из аккаунта» или управление устройствами в Telegram.

Приложение взаимодействует с Telegram через Telethon. Собственного сервера, аналитики и автоматического отправления журналов нет. Ссылка помощи открывается в браузере. Перед отправкой журнала удалите личные данные.

## Ограничения беты
Windows x64. Сборка не подписана цифровым сертификатом. Для первой беты необходима проверка на другом компьютере. Наличие ненулевого файла не гарантирует, что его изображение или видео не повреждено. Изменения Telegram API могут влиять на работу. Истории, уже недоступные через API, восстановить нельзя.

Поддерживаются русский, английский, украинский, испанский, португальский, итальянский, турецкий, персидский, арабский, хинди и индонезийский. Переводы требуют проверки носителями.

При сообщении об ошибке укажите версию Windows, язык программы, ожидаемый результат и фактический результат. Не присылайте API Hash, сессию, телефон и личные фотографии.
